# Source Code (`src/`)

Core Python logic for SOC Triage Automation.

## Files

- `__init__.py`: Python package marker
- `ai_triage_engine.py`: Main AI triage engine (Rule-based, ML, LLM methods)
- `metrics_calculator.py`: Evaluates AI performance against ground truth

## Usage

```bash
# Run AI triage
python src/ai_triage_engine.py

# Calculate metrics
python src/metrics_calculator.py
